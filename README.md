## 🚀 Featured Project

### 🔥 AI-Powered Test Automation Framework

👉 https://github.com/Shukla0312/ai-powered-test-automation

**What it does:**
- Replaces brittle assertions with **semantic validation using LLMs**
- Validates API responses based on **intent, not exact values**
- Combines **schema validation + AI reasoning** for reliability

**Key Highlights:**
- 🧠 AI-based validation (PASS/FAIL + reasoning + confidence)
- 🔁 Retry logic, caching, and rate-limit handling
- ⚙️ Config-driven execution (mock vs real AI)
- 🧩 Modular architecture (services, validator, decision engine)
- 📊 Real-world API validation (ReqRes, REST Countries)

**Why it matters:**
Traditional automation checks exact values.  
This framework validates **correctness intelligently**, reducing flaky tests.
